# Minesweeper (tkinter)

> **⚠️ このリポジトリのコードおよびドキュメントは生成AI（AIアシスタント）によって作成・更新されています。**

Python + tkinter で動作するデスクトップ向けマインスイーパーです。

## 動作環境

- Python 3.10 以上
- tkinter（標準ライブラリ）

## 起動方法

```bash
python src/main.py
```

## 主な機能

- 難易度プリセット（初級 / 中級 / 上級）
- カスタム盤面サイズ（行・列・地雷数）
- 左クリックで開く、右クリックで `旗 → ? → 未設定`
- 初手安全ルール（最初に開いたマスは地雷にならない）
- ウインドウの拡大縮小に追従する盤面レイアウト

## テスト実行

```bash
pytest -q
```
